# Ahmed Chaudhry — Portfolio website

A mobile-responsive all-black portfolio website with white text and local company logos, ready for free GitHub Pages hosting.

## Preview

Open `index.html` in a browser. The five supplied logos are included as optimized, locally stored assets in `assets/`, so you don't need external logo image hosting. The résumé button opens `resume.pdf`.

## Publish free with GitHub Pages

1. Sign in to GitHub and create a new public repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Choose **Add file → Upload files** and upload **everything inside this website folder**, including `index.html`, `favicon.svg`, `resume.pdf` and the complete `assets` folder. Keep `index.html` at the repository root.
3. Go to **Settings → Pages** and set **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**, and click Save.
4. Open `https://YOUR-GITHUB-USERNAME.github.io/` once publishing is complete.

## Edit it

Edit `index.html` to update any text, projects, links, and experience. CSS colors are defined at the top of the file.

## Privacy

The included `resume.pdf` is the uploaded résumé, including the original phone number. Remove it from the résumé if you don't want to publish your phone number.
